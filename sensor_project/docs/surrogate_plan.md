# 后续降维与 real2sim 数据

本次交付的七条 compression 轨迹可用于检查形变、磁铁位姿和 Hall 趋势，不足以独立证明对任意压头和剪切的泛化能力。本次不包含训练模型或 shear 数据。

高维形变数据应保留硅胶全部节点 U、初始坐标、网格拓扑、工况和步骤/帧信息。不同模型网格不同，POD/PCA 前需要统一节点映射或采样坐标，不能直接按节点编号拼接。

磁铁运动由空腔 RP 耦合给出；Hall 计算使用圆柱磁场模型。真实数据锚点应对齐接触零点、压缩位移、坐标轴和 Br，并采用独立工况验证修正效果。

摩擦、空腔、材料和实验误差对响应均有影响。神经网络修正不能替代有限元物理检查；训练时保留输入配置、求解状态与真实数据来源，避免把失败帧或数据泄漏纳入评估。
