# FEM Surrogate V1：输入输出定义与技术路线

## 1. 项目目标

建立一个基于 Abaqus 有限元数据的物理代理模型，用于预测磁性触觉传感器在不同接触条件下的力学和磁场响应。

技术路线为：

```text
Abaqus FEM -> 数据提取 -> PCA 降维 -> Surrogate Network -> Real-to-Sim 校准
```

当前阶段只验证固定标准压头、不同接触位置和不同压入深度下的前向映射关系，暂不考虑 Isaac Sim 集成和复杂摩擦。

## 2. 输入定义

V1 输入分为 Geometry、Pose 和 Loading 三个模块。

### 2.1 Geometry：接触几何

V1 使用四种固定尺寸的标准压头：

- 球面压头（Sphere）
- 圆柱面压头（Cylinder）
- 平面压头（Flat）
- 三角形平面压头（Triangle）

几何暂不连续参数化，不使用 SDF 或几何 PCA。每种压头使用独立的固定 CAD 几何模型，并用 one-hot 向量表示：

```text
G = [g1, g2, g3, g4]
```

### 2.2 Pose：接触位姿

接触位姿为：

```text
P = [x_c, y_c, theta]
```

- `x_c`：皮肤初始表面上的名义接触位置 X 坐标
- `y_c`：皮肤初始表面上的名义接触位置 Y 坐标
- `theta`：压头绕接触法向的旋转角度

V1 不考虑压头倾斜，法向加载方向固定。球面压头具有旋转对称性，`theta` 对其几何没有影响；圆柱面和三角形压头的 `theta` 会改变接触方向。

网络实现时，角度使用 `sin(theta)` 和 `cos(theta)` 编码，避免周期边界不连续。

### 2.3 Loading：接触加载

加载采用位移控制：

```text
L = [delta_n, delta_x, delta_y]
```

- `delta_n`：法向压入深度
- `delta_x`：X 方向切向位移
- `delta_y`：Y 方向切向位移

压入深度以首次接触未变形皮肤的位置为零点，不使用压头绝对 Z 坐标。

V1 第一阶段只考虑法向压入：

```text
delta_x = 0
delta_y = 0
```

切向位移保留接口，待法向模型验证通过后再加入。

### 2.4 V1 输入向量

完整预留输入为：

```text
X = [G, x_c, y_c, theta, delta_n, delta_x, delta_y]
```

V1 法向阶段为：

```text
X_V1 = [G, x_c, y_c, theta, delta_n]
```

采用三角函数编码后，实际网络输入为：

```text
[G, x_c, y_c, sin(theta), cos(theta), delta_n]
```

输入维度为 `4 + 1 + 1 + 2 + 1 = 9`。

### 2.5 固定条件

以下因素不作为 V1 网络输入：

- 摩擦系数和复杂摩擦状态
- 材料参数
- 磁铁空腔配置

它们在 V1 数据集内保持固定，并作为数据集元数据保存。材料和空腔配置仍会影响 FEM 响应，因此配置发生变化时，不能直接认为现有网络仍然有效，需要重新训练或校准。

## 3. 输出定义

### 3.1 弹性体形变

从 Abaqus 提取弹性体指定节点的三维位移场。使用 PCA 降维：

```text
u ~= u_mean + W_k @ a_PCA
```

网络预测 `a_PCA`。所有工况必须使用统一的参考网格和节点对应关系。

训练时保留完整节点位移数据，不能只保存 PCA 系数。

### 3.2 磁铁位姿

输出每个磁铁的六自由度位姿：

```text
T_Mi = [x_i, y_i, z_i, qx_i, qy_i, qz_i, qw_i]
```

位置表示磁铁中心坐标，姿态使用单位四元数。必须统一全局坐标系、四元数符号约定，并以磁铁初始位姿作为参考。

### 3.3 Hall 磁场

所有 Hall 传感器的三轴磁场为：

```text
B = [Bx1, By1, Bz1, ..., BxN, ByN, BzN]
```

优先根据网络预测的磁铁位姿，再通过已经验证的磁场模型计算 Hall 信号：

```text
Magnet Pose -> Magnetic Field Model -> Hall B
```

后续可以增加神经网络残差校准模块，修正磁场模型与真实测量之间的误差。

### 3.4 接触合力

V1 输出接触三轴合力：

```text
F = [Fx, Fy, Fz]
```

后续扩展为六维接触力矩：

```text
W = [Fx, Fy, Fz, Mx, My, Mz]
```

合力和力矩从 Abaqus 接触反力或接触牵引积分提取，并统一作用对象、坐标系和正负号约定。

### 3.5 接触压力分布

V1 重点提取法向接触压力场 `p_n(x, y)`。将压力映射到统一的皮肤参考表面网格，非接触区域设为零，再使用 PCA 降维：

```text
p_n ~= p_mean + W_p @ a_contact
```

网络预测：

```text
a_contact = [c1, c2, ..., ck]
```

同时保存接触面积、接触区域掩膜、压力中心和最大接触压力。接触压力 PCA 预测头可作为辅助任务逐步启用。

切向接触应力和 Stick/Slip 状态属于后续摩擦阶段，不作为 V1 完成条件。

## 4. Surrogate 数学表达

整体前向映射为：

```text
f_theta(Geometry, Pose, Loading)
    -> (Deformation_PCA, Magnet_Pose, Hall, Contact_Force, Contact_Stress_PCA)
```

V1 法向阶段为：

```text
f_theta(G, x_c, y_c, theta, delta_n)
    -> (a_PCA, T_M, B, F, a_contact)
```

建议采用共享特征网络加多个物理输出头，也可以根据物理依赖关系使用分层预测结构。各输出量分别归一化、分别评估。

## 5. Abaqus 自动化与数据生成

建立统一参数化仿真脚本，完成：

1. 选择固定标准压头 CAD 模型。
2. 设置接触位置和压头绕法向的旋转角度。
3. 自动确定首次接触参考高度。
4. 施加法向压入位移。
5. 执行几何非线性有限元求解。
6. 提取弹性体三维位移场。
7. 提取所有磁铁中心位置和姿态。
8. 提取接触合力和接触压力分布。
9. 根据磁铁位姿计算 Hall 磁场。
10. 保存统一格式的训练数据和工况元数据。

数据集应覆盖不同压头、接触位置、旋转角度和压入深度，并保留未参与训练的完整工况用于泛化验证。

在法向接触模型达到目标精度后，再加入切向加载。

## 6. Real-to-Sim 校准

使用现有 XYZ 实验台、六维力传感器和 Hall 阵列进行验证。

实验输入与 FEM 保持一致：

```text
[G, x_c, y_c, theta, delta_n]
```

实验主要测量：

- 三轴接触力
- Hall 阵列磁场
- 压头位置和压入深度

先完成材料参数辨识和 FEM 响应验证，再训练 Surrogate 和进行真实数据残差校准。使用独立实验工况验证泛化能力。

## 7. 下一代扩展方向

### 7.1 Geometry 参数化

V1 验证通过后，将固定标准压头升级为参数化压头：

- Sphere：半径 `R`
- Cylinder：半径 `R`、长度 `L`
- Flat：尺寸和形状参数
- Triangle：边长、夹角和圆角半径

进一步扩展为：

```text
CAD / Mesh -> SDF -> PCA / Autoencoder -> Geometry Latent Vector
```

新增几何参数时，需要扩充 FEM 数据并重新训练或微调网络，同时保留旧工况验证。

### 7.2 复杂接触与摩擦

法向接触模型稳定后，再逐步增加：

- 切向位移和切向力
- 摩擦系数和表面状态
- Stick / Partial Slip / Slip
- 加载历史和速度
- 摩擦路径依赖

复杂摩擦不作为 V1 的完成前提。

## 8. 当前开发原则

1. V1 固定 Geometry，参数化 Pose 和 Loading。
2. 先完成法向接触，再研究切向摩擦。
3. 弹性体形变采用 PCA 降维。
4. 接触压力场使用统一网格保存，并可进一步 PCA 降维。
5. 磁铁位姿、Hall、接触合力和接触压力属于核心物理输出。
6. 保留完整 FEM 原始数据，不仅保存 PCA 系数。
7. 材料参数和空腔配置作为固定条件记录，不作为 V1 网络输入。
8. 模型设计支持后续增加压头几何参数和摩擦状态。
9. 暂不考虑 Isaac Sim 对接。

## V1 核心目标

建立一个经过真实实验验证、能够准确预测固定标准压头在不同接触位姿和压入深度下的弹性体形变、磁铁位姿、Hall 磁场、接触力及接触压力分布的可扩展 FEM Surrogate。
