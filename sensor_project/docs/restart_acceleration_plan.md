# 压缩检查点与后续剪切重启动

## 当前交付状态

七个 compression 工况已完成，每个 ODB 有接触步及六个压缩步，可以读取 0.5、1、1.5、2、2.5、3 mm 的状态。但本次交付没有可直接读取的完整求解 restart 文件，也没有 shear 分支结果。

当前生成器和保留的 INP 使用 `*Restart, write, frequency=0`；不能把这理解为“已保存每步末的可用重启动检查点”。Abaqus/Standard 中 frequency=0 关闭 restart 写出。CAE/ODB 不是 restart 求解数据的替代品。

## 后续实施流程

1. 在独立目录生成压缩基线，按已安装版本的官方说明启用 restart 写出，例如使用非零写出频率；若要保留多个状态，不启用覆盖旧状态的 OVERLAY。
2. 先完成一个小规模基线，确认其求解 restart 文件存在，并实际读入一个检查点做单分支验证。
3. 保持基线的网格、材料、接触、RP 耦合和法向位移，使用 Standard 的 restart read 读取指定压缩状态。
4. 每个剪切分支独立从压缩基线启动，不把上一个剪切结果作为下一个分支的初态。
5. 核对分支初始位姿、压缩深度、反力与基线一致，再施加局部切向位移。
6. 先验证 P25_Np00_Y0 的单一分支，再扩展六个压缩深度。

本次不提供已验证的 restart/shear 提交脚本。生成器现有写出设置保持与交付模型一致，重新计算前必须明确修改并验证 restart 策略。
