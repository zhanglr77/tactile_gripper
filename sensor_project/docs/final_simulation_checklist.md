# 仿真检查清单

## 建模前

- 核对传感器单位、全局原点、硅胶 STEP。
- 核对六个磁铁的尺寸、中心、轴向、空腔和 RP 耦合。
- 核对四个 Hall 的位置与局部轴。
- 核对解析压头形状、单侧法向、主从面、初始间隙和加载方向。

## 提交前

- 使用独立工况目录，检查 case.json、CAE、INP 一致。
- 通过 datacheck，确认实际摩擦为 0.5。
- 核对每 job 4 CPU、10% 内存上限；并行数量根据目标电脑资源设置。
- 若需要后续 restart，先验证非零 restart 写出和读取；当前交付不具备直接 restart 数据。

## 结果验收

- 必须有成功结束标记；七个交付 job 均已满足。
- 确认六个压缩步末达到 0.5–3 mm，而非把闭合初始间隙计入压缩。
- 检查变形、接触穿透、反力平衡、警告、能量和磁铁位姿。
- Hall 导出前检查 RP U/UR 完整性。
- 当前结果仅代表 compression，不计作 shear 或实验一致性验证。
