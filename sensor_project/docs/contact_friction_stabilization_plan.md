# 接触、摩擦与收敛

本次采用 Hard normal contact、允许分离、有限滑移、各向同性 penalty 摩擦，系数 0.5；弹性滑移比例容差 0.005。解析压头为主面，硅胶为从面。

该设置下，本次七个带空腔工况全部完成 3 mm compression。它是当前可复现的求解参数，不代表摩擦已由实验标定。摩擦变化会改变形变、反力和磁铁位姿，不能仅为提高成功率而忽略其物理影响。

当前压缩步没有额外人工稳定化设置。若后续增加稳定化、改变步长或接触控制，应独立记录配置，检查能量占比并与原模型对照。

检查每例 `.msg` 中的回退、穿透、数值警告和终止原因；查看失败前最后收敛帧。不要把成功结束直接等同于接触和材料模型已验证。
